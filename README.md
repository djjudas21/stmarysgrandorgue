# stmarysgrandorgue
GrandOrgue files for St Mary's, Fishponds

[The organ at St Mary's, Fishponds](https://stmarysfishponds.org.uk/music/organ/) has never been sampled.
However, we can approximate the sound by borrowing samples of other organs with similar-sounding stops.

This "composite" sampleset for Fishponds is borrowed from
[St. John Cantius in Cracow, Poland ](https://piotrgrabowski.pl/cracow-st-john-cantius/), which is
available free of charge from Piotr Grabowski. To use this definition file, you will need to download that sampleset.

The `.odp` file is a project file for a tool called [Organ Builder](https://drive.google.com/open?id=0B7o0RGQx9qJgWFkyN0R4QmJPREk).
Unfortunately, the project seems to have been abandoned in late 2014/early 2015 and the website for Organ Builder is defunct,
but the tool still works.

The `.organ` file is a GrandOrgue defintion file, exported by Organ Builder.
